# Astral VPN v2.2.39 - temiz Windows ve portable paket doğrulaması

Tarih: 2026-08-07

v2.2.39, v2.2.38'deki Discord gerçek erişim düzeltmelerini korur ve dağıtım paketinin kullanıcı hesabına, repo yoluna veya önceden kurulmuş .NET çalışma zamanına bağlı olmadığını otomatik release kapısına bağlar. Paket bilerek Authenticode imzası taşımaz; Windows SmartScreen uyarı gösterebilir.

## Portable ve temiz-PC kapısı

- `Astral-2.2.39-win-x64.zip` boşluk ve Türkçe karakter içeren yeni bir geçici klasöre açılır.
- SHA-256 sidecar, update manifest sürümü, manifestteki her dosyanın boyutu/özeti, eksik veya fazla dosyalar ve ZIP path traversal girdileri doğrulanır.
- `Astral.exe`, `Astral.Updater.exe` ve `Astral.WebProxy.exe` PE başlıklarının x64 olduğu doğrulanır.
- Self-contained .NET runtime dosyaları, companion executable'lar ve paketli H.264 arka plan videosu zorunludur.
- Ana uygulama `--portable-package-self-test` ile kullanıcı profili, mutex, VPN, PAC, firewall veya açık Astral örneğine dokunmadan gerçek paket kökünden başlayıp başarıyla çıkar.
- Tam paket zinciri temiz `windows-2022` ve `windows-2025` GitHub runner'larında çalışır; release workflow'u aynı doğrulamayı tekrar zorunlu tutar.

## Destek sınırı

- Desteklenen dağıtım: Windows 10/11 x64.
- Paket self-contained .NET 8 runtime içerir; son kullanıcıya .NET SDK/runtime kurulumu gerekmez.
- WireSock kurulu değilse kullanıcı onayından sonra sabit resmi URL'den indirilir ve SHA-256, Authenticode, yayıncı, ürün adı ve sürümle doğrulanır. Release ZIP'inde doğrulanmış yerel MSI varsa aynı güven kapısıyla yeniden kullanılabilir.
- ARM64, x86, Windows 8.1 ve daha eski Windows sürümleri bu release kapsamı dışındadır.
- Kurumsal güvenlik yazılımı, ağ filtreleri, üçüncü taraf servis durumu ve cihaz politikaları her fiziksel PC için uzaktan garanti edilemez; CI ve gerçek Windows kanıtları desteklenen sözleşmeyi doğrular.

## Otomatik doğrulama

- Astral.Core.Tests: 162/162.
- Astral.WebProxy.Tests: 3/3.
- Astral.Updater.Tests: 3/3.

Public ZIP özeti bu dosyaya gömülmez; GitHub release asset digest'i ve yanında yayımlanan `.sha256.txt` dosyası yayın tamamlandıktan sonra doğrulanır.
