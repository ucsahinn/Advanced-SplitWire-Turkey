# Astral VPN v2.2.35 - Güvenlik ve kalite hotfix'i

Tarih: 2026-07-26

v2.2.35, v2.2.34 üzerine WebProxy ağ sınırlarını, azaltılmış hareket davranışını, test görünürlüğünü ve release güvenlik kapılarını sıkılaştıran bir patch sürümüdür.

## Değişenler

- `Astral.WebProxy` yalnız HTTP/80 ve CONNECT/443 uçlarına izin verir.
- Allowlist içindeki bir host loopback, private, link-local, multicast, CGNAT veya özel IPv6 adresine çözülürse upstream bağlantı reddedilir. Bağlantı, kontrolden geçen IP adresine yapılarak DNS yeniden çözümleme yarışı daraltılır.
- Proxy aynı anda en fazla 64 istemci işler; eksik header gönderen yavaş istemciler 10 saniyede `408 Request Timeout` alır.
- HTTP absolute URI ile `Host` başlığı aynı authority'yi göstermiyorsa istek reddedilir; special-use IPv4 ve NAT64 aralıkları upstream olamaz.
- CONNECT tünellerinde trafik geldikçe yenilenen iki dakikalık idle timeout, boş bağlantıların proxy kapasitesini kalıcı tüketmesini engeller.
- Windows azaltılmış hareket tercihi açıkken arka plan videosu ve sürekli hedef rozet pulse animasyonları devre dışı kalır.
- Üç geçerli Discord launch-plan testi gerçek Core test runner'a alındı; güncel ürün davranışıyla çelişen on iki eski test gövdesi kaldırıldı.
- CI ve release workflow'ları Gitleaks `8.30.1` Windows x64 arşivini exact sürüm ve SHA-256 ile doğrular. `verify.ps1 -RequireGitleaks`, Git geçmişi ve çalışma ağacı secret scan'i çalışmadan başarı vermez; release publish dizini ayrıca taranır.
- Resmi release Authenticode imzası olmadan yayımlanmaz. İmzalı Astral, WebProxy ve Updater yardımcı ikililerinin aynı yayıncı imzasıyla eşleştiğini çalışma anında doğrular; güncelleme paketi PE dosyaları da mevcut imzayla eşleşir.
- Resmi WebProxy tek self-contained executable olarak paketlenir; yönetici ACL'li ve reparse-point korumalı oturum staging alanına kopyalanıp yeniden doğrulandıktan sonra oradan çalıştırılır. Native bundle extraction için `DOTNET_BUNDLE_EXTRACT_BASE_DIR` aynı korumalı alana sabitlenir.
- README ve katkı rehberi .NET SDK önkoşulunu, ilk bağlantının yönetici/ağ/sistem etkilerini, kanonik doğrulama komutunu ve manuel ZIP SHA-256 kontrolünü açıklar.
- Hata bildirim şablonundaki artık desteklenmeyen Roblox örneği kaldırıldı.

## Güvenlik sınırı

- Tarayıcı süreçleri WireSock `AllowedApps` listesine eklenmez.
- Web hedefleri PAC + `Astral.WebProxy.exe` kapsamıyla sınırlıdır.
- HTTPS içeriği çözülmez, sertifika kurulmaz ve TLS MITM yapılmaz.
- Proxy host allowlist'i korunur; yeni endpoint politikası port ve çözülen IP adresi sınırını ayrıca uygular.
- Güncelleme paketi Authenticode, GitHub release digest'i, SHA-256 dosyası ve update manifest ile doğrulanır.
