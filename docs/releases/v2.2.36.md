# Astral VPN v2.2.36 - Sertifikasız dağıtım hotfix'i

Tarih: 2026-08-07

v2.2.36, v2.2.35'te tamamlanan WebProxy güvenlik ve kalite sıkılaştırmalarını sertifikasız public dağıtım politikasıyla yayımlar. v2.2.35 etiketi imza kapısında güvenli biçimde durmuş, public release oluşturmamıştır; mevcut etiketi yeniden yazmak yerine yeni sürüm kullanılır.

## Dağıtım ve güven sınırı

- Bu sürümün Windows executable dosyaları Authenticode imzası taşımaz.
- Windows doğrulanmış yayıncı kimliği göstermez ve SmartScreen uyarısı çıkarabilir.
- Workflow yalnız `signed` veya `unsigned` imza durumunu kabul eder; gerçek durum release notuna eklenir.
- Git geçmişi, çalışma ağacı ve publish çıktısı Gitleaks ile taranır.
- GitHub asset digest, versioned/stable SHA-256 dosyaları ve `astral.update-manifest.json` eşliği zorunludur.
- Sertifika daha sonra iki secret ile birlikte yapılandırılırsa aynı workflow imzalı paket üretmeye devam edebilir.

## Korunan v2.2.35 güvenlik düzeltmeleri

- WebProxy çıkışı yalnız public HTTP/HTTPS uç noktalarıyla sınırlıdır; özel ve special-use adresler ile DNS rebinding yolları reddedilir.
- CONNECT authority, Host ve absolute-URI authority sapmaları engellenir.
- Yavaş header, eşzamanlı istemci ve boşta tünel sınırları kaynak tüketimini kısıtlar.
- WebProxy korumalı oturum staging alanından çalışır; imzalı build yolu kullanıldığında companion imza doğrulaması korunur.
- Azaltılmış hareket tercihinde arka plan videosu ve sürekli durum animasyonları kapatılır.

## Doğrulama

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify.ps1 -RequireGitleaks
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-release.ps1 -RequireGitleaks
```

Beklenen public assetler:

- `Astral-2.2.36-win-x64.zip`
- `Astral-2.2.36-win-x64.sha256.txt`
- `Astral-win-x64.zip`
- `Astral-win-x64.sha256.txt`

İmzalı paket gerekiyorsa `build-release.ps1` ayrıca sertifika yolu ve `-RequireCodeSigning` ile çalıştırılmalıdır; bu sürümün public paketi için bu seçenek kullanılmaz.
