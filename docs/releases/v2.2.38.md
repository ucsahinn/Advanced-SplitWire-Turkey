# Astral VPN v2.2.38 - Discord gerçek erişim hotfix'i

Tarih: 2026-08-07

v2.2.38, Astral'ın bağlantı hazır göstermesine rağmen Discord web ve masaüstü uygulamasının çalışmamasına yol açan iki kök nedeni giderir. Paket Authenticode imzası taşımaz; bütünlük GitHub asset digest'i, SHA-256 sidecar dosyaları, update manifest ve zorunlu Gitleaks taramasıyla doğrulanır.

## Düzeltmeler

- Scoped WebProxy kanıtı artık yalnız `CONNECT 200` cevabını başarı saymaz. Proxy tüneli üzerinden hedefe gerçek TLS el sıkışması yapar, HTTP isteği gönderir ve yalnız 2xx-4xx hedef yanıtını doğrulanmış kabul eder.
- WireSock aktifken sistem DNS'inin hedefi `::1` veya `0.0.0.0` gibi non-public engel adreslerine çözmesi durumunda Astral.WebProxy güvenli DoH/UDP fallback yolunu kullanır. Upstream bağlantısı yine yalnız public HTTP/HTTPS adreslerine izin verir.
- wgcf'nin Cloudflare WARP IPv6/hostname endpoint'i, WireSock 1.4.7 sanal adaptör modunda doğrulanan IPv4 Anycast endpoint'ine normalize edilir. Bu, IPv6 endpoint'inde gözlenen tekrarlayan “WireGuard Server is unreachable” döngüsünü önler.
- Optimize edilmiş yerel H.264 arka plan videosu, azaltılmış hareket davranışı ve bozuk-dosya nötr fallback'i korunur.

## Gerçek Windows Kanıtı

- İlk yeniden üretimde Astral 2.2.37 `webProxyProof.verified=True` raporlarken `wireSockConnectionEstablished=False` idi; Discord web doğrudan ve scoped proxy üzerinden zaman aşımına uğradı.
- Kontrollü WireSock debug koşusunda sistem DNS'i `discord.com` için `::1, 0.0.0.0` döndürdü ve eski WebProxy `CONNECT 502` üretti.
- Düzeltilmiş WebProxy + korumalı WARP profiliyle gerçek `https://discord.com/app` isteği `HTTP 200` döndürdü; TLS yaklaşık 0.99 saniye, toplam yaklaşık 1.21 saniye sürdü.
- Tam Astral GUI Discord smoke testi geçti: WireSock adaptörü `Up`, adapter trafik artışı mevcut, uygulama hedef kanıtı `discord=True`, scoped WebProxy TLS/HTTP kanıtı `1/1` ve bağlantı durumu `ready`.
- Tam web-only GUI smoke testi geçti: hedef TLS/HTTP kanıtı `1/1`, hedef testi `1/1`, PAC/firewall/hosts/ayar restorasyonu ve normal kapanış doğrulandı.
