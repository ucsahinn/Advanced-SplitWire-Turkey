# Astral VPN v2.2.37 - Canlı bağlantı dayanıklılığı hotfix'i

## Özet

v2.2.37, v2.2.36 Windows tanılamasında görülen Cloudflare WARP kayıt hatasının kök nedenini giderir ve canlı profil smoke testinin yanlış-pozitif/cleanup kapılarını sıkılaştırır. Sertifikasız dağıtım politikası değişmez: paket Authenticode imzası taşımaz; bütünlük GitHub asset digest, SHA-256 dosyası, update manifest ve zorunlu Gitleaks taramasıyla doğrulanır.

## Düzeltmeler

- `wgcf`, v2.2.31'in TLS parmak izi regresyonunu düzelten v2.2.32'ye yükseltildi. Windows x64 executable indirmesi resmi GitHub release URL'sine ve `2b3648a5d39550b6423be562e619805ed9f7a64bcda51cf36c60caeba97b1777` SHA-256 özetine sabitlendi.
- `wgcf register` yine HTTP 429 döndürürse Astral otomatik yeniden kayıt çağrısı yapmaz; birkaç dakika bekleyip kullanıcı tarafından yeniden denenmesini ister.
- Sürekli 429 durumunda ham wgcf stack çıktısı kullanıcı detayına taşınmaz; birkaç dakika bekleyip yeniden denemeyi öneren açık Türkçe mesaj gösterilir.
- Başarısız register çağrısı hesap dosyasını oluşturmuşsa yinelenen kayıt atlanır ve profil üretimine devam edilir.
- Scoped proxy fallback metnindeki bozuk Türkçe düzeltildi.
- WebProxy, HTTP başlıklarıyla gövdenin aynı TCP okumasında gelmesini doğru ayırır; ilk gövde baytlarını upstream'e eksiksiz ve yalnız bir kez iletir.
- Updater rollback sırasında bir dosya geri yüklenemese bile kalan dosyaları geri yüklemeyi sürdürür ve karışık kurulum olasılığında yanlış “mevcut sürüm korundu” mesajı vermez.
- Güncelleme staging alanı yalnız Astral'a ait olduğu doğrulanan tamamlanmış/terk edilmiş denemeleri temizler; aktif, işaretsiz, reparse-point içeren veya erişilemeyen ağaçları güvenli biçimde korur. Saklama sınırı üç deneme ve yedi gündür.
- Kullanıcı pencere veya bildirim alanından çıkarken controller cleanup hızlı biçimde hata verirse uygulama sessizce kapanmaz; pencereyi geri açar, yeniden denemeye ve tanı paketi oluşturmaya izin verir. Cleanup süre sınırını aşarsa UI kapanır, işlem 30 saniyelik ek sınır boyunca arka planda izlenir ve tamamlanma, hata veya ikinci zaman aşımı tanılamaya yazılır.
- Uygulama hedefi kanıtı artık yalnız süreç adına güvenmez: canonical executable yolu ve hedefin doğrulanmış `443` bağlantısı gerekir; aynı adlı sahte executable ve farklı port reddedilir.
- Azar, Tango ve LiVU güncel resmi dağıtım yüzeyleriyle uyumlu olarak web kapsamına alındı; bunlar için var olmayan Windows executable adları artık WireSock uygulama kanıtı istemez. LiVU rotası güncel `livuapp.com` alanlarını içerir ve eski `livu.me` alanlarını uyumluluk için korur.
- IMVU uygulama yolu yalnız korumalı `Program Files` köklerinden kabul edilir. Makine App Paths kaydı yalnız keşif ipucudur ve gösterdiği executable yine bu korumalı kökün, exact dosya adının ve reparse kontrollerinin tamamını geçmelidir; kullanıcı-yazılabilir LocalAppData veya gevşek yayıncı-adı eşleşmesi güven kökü değildir. WireSock kapsamı ile proof aynı rooted yolu kullanır.
- Uygulama ilk bağlantıdan sonra keşfedilirse aktif WireSock profili yerinde genişletilmez; arayüz yeni güvenli kapsamın uygulanması için bağlantıyı kesip yeniden bağlamayı açıkça ister.
- Profil temizleme ve bakım akışları doğrulanmayan controller/WebProxy/PAC/tünel/hedef-kilidi temizliğinde fail-closed kalıp kullanıcıya yeniden deneme olanağı verir. Normal pencere çıkışı ise UI'nin süresiz kilitlenmemesi için yukarıdaki bounded background-shutdown politikasını kullanır.
- Güncelleme dosyaları uygulandıktan sonra Astral yeniden başlatılamazsa Updater artık yanlış “mevcut sürüm korundu” mesajı vermez; elle açma/onarım yönlendirmesi gösterir.
- Yükseltilmiş uygulama uzak CDN videosu oynatmaz. Optimize edilmiş H.264/yuv420p video release paketinden yerel olarak oynatılır; dosya yoksa veya bozuksa nötr görsel fallback kullanılır.
- Canlı smoke testi seçili web ve uygulama hedef kimliklerini exact set olarak doğrular.
- Smoke sırasında `RunInBackgroundOnClose=false` geçici olarak zorlanır; uygulama normal kapanmazsa test PASS vermez.
- Test sonrasında settings byte-for-byte geri yüklenir. Önceki `AutoConfigURL`, PAC/state artıkları, hosts kilidi, firewall kuralı ve WireSock/WebProxy kapanışı zorunlu postcondition'dır.

## Bilinen dış sınır

Astral, resmi olmayan `wgcf` istemcisini kullanır. v2.2.32, v2.2.31'de değişen TLS parmak izini önceki sürümlerle uyumlu hale getirerek gözlenen kayıt regresyonunu giderir. Cloudflare ayrıca yeni WARP hesabı oluşturmayı IP veya zaman penceresi bazında sınırlandırabilir; hesap/profil olmadan tünel kurulamaz. v2.2.37 bu dış kısıtı gizlemez veya güvenlik kapılarını zayıflatmaz; istek sayısını sınırlar, mevcut hesap oluşmuşsa güvenle devam eder ve kullanıcıya eyleme dönük durum verir.

## Dağıtım notu

Windows SmartScreen, Authenticode imzası olmayan pakette uyarı gösterebilir. Yalnız resmi GitHub release varlığındaki ZIP'i kullanın ve `.sha256.txt` özetiyle doğrulayın. Bu özet bütünlük tutarlılığı sağlar, yayıncı kimliğini kanıtlamaz; portable klasörü doğrulama sonrasında başka süreçlerin değiştiremeyeceği güvenilir bir konumda tutun.
