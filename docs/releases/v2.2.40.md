# Astral VPN v2.2.40 - güncelleme denetimi erişim düzeltmesi

Tarih: 2026-08-07

v2.2.40, başlangıç güncelleme denetimi ağ, DNS, GitHub API veya geçici servis hatasıyla sonuçlansa bile güncelleme denetimi düğmesini görünür bırakır. Kullanıcı uygulamayı yeniden başlatmadan aynı düğmeyle denetimi yeniden çalıştırabilir. Paket bilerek Authenticode imzası taşımaz; Windows SmartScreen uyarı gösterebilir.

## Düzeltme

- Üst çubuktaki düğme, güncelleme bulunmadığında `Denetle` olarak görünür ve elle denetim başlatır.
- Denetim sürerken düğme `Denetleniyor` durumuna geçer ve yinelenen istekleri engeller.
- Yeni sürüm bulunduğunda aynı düğme `Güncelle` eylemine dönüşür.
- Başlangıç denetimi başarısız olduğunda düğme artık gizlenmez; tanı durumu hatayı bildirirken tekrar deneme yolu erişilebilir kalır.
- Başarılı güncelleme bulma ve tekrarlanan GitHub HTTP 503 hatası ayrı gerçek WPF senaryolarıyla doğrulanır.

## Eski sürümden geçiş

v2.2.34'te başlangıç denetimi başarısız olduysa düğme gizli kaldığı için bu düzeltmeye uygulama içinden ulaşılamayabilir. Böyle bir kurulumda resmi `Astral-2.2.40-win-x64.zip` paketi bir kez elle indirilip mevcut Astral klasörünün yerine açılmalıdır. Kullanıcı ayarları `%LOCALAPPDATA%\Astral` altında kaldığından portable uygulama klasörünü yenilemek ayarları silmez.

## Korunan release kapıları

- Desteklenen dağıtım Windows 10/11 x64 ve self-contained .NET 8 paketidir.
- ZIP; GitHub asset digest'i, SHA-256 sidecar ve update manifest ile doğrulanır.
- Portable paket Unicode/boşluk içeren yolda, x64 PE denetimi ve gerçek başlangıç self-test'iyle sınanır.
- Optimize edilmiş yerel H.264 arka plan videosu, azaltılmış hareket ve bozuk-dosya fallback davranışı korunur.
- Gitleaks Git geçmişini, çalışma ağacını ve publish paketini tarar.

Public ZIP özeti bu dosyaya gömülmez; GitHub release asset digest'i ve yanında yayımlanan `.sha256.txt` dosyası yayın tamamlandıktan sonra doğrulanır.
